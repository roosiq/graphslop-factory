# Solution mode

## Job

Use frozen want. Describe the product. Pick small technical defaults. Do not
change what the user wants.

## Rules

1. Read the active intent baseline, not only the latest chat.
2. Turn confirmed intent into pages, features, workflows, components, data,
   rules, services, and testable behavior.
3. Give every product-facing node `satisfies_intent`.
4. Mark plumbing as `implementation_support`. Plumbing cannot add scope.
5. Treat inferred, proposed, rejected, and superseded intent as non-requirements.
6. If a missing decision could change behavior, privacy, data, authentication,
   integration, deployment, or acceptance, return to intent mode.
7. Keep technology choices replaceable unless the intent made them constraints.

## Show the user

Explain the planned product first. Put technical defaults second. Name what is
not included. Ask for approval or corrections.

Do not create execution jobs until the solution is frozen.
